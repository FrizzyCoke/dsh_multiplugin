# 2026-11-18 打分标尺（按口味和记忆算） + 桌宠真的走过去

## 一、打分
**现象**：分数（0~20）决定分享 / 每日动态 / 心情 / 关注 / 出去逛的战绩，但只有「每项 0-4，满 20」，五项从没定义给她 → 全凭感觉。
`debrief --score` 里藏着一张旧卡（信息密度 / 表达质量…），提示从不让她用，而且跟她的口味对着干（标题党在她爱看里却扣分）。

**修法**（`tools/lib/score-rubric.mjs`）：20 分拆 6 项，14 分代码算：
| 项 | 分 | 谁定 | 依据 |
|---|---|---|---|
| 口味 | 6 | 代码 | 她勾的类别（只能从配置的 like 里选）× 口味权重 + 标题/标签字面命中加分；勾了 / 出现不爱看的 → 封顶 6 |
| 他会喜欢 | 4 | 代码 | 视频分区（view 接口 tname）对上他观看历史的口味（分区名对分区名） |
| 记忆 | 2 | 代码 | 跟收藏 / 最近高分 / 逛过的方向 / 梗沾边（权重小，防自我强化） |
| 新鲜 | 2 | 代码 | 只罚近似重复（同 UP 近同标题、或标题几乎一样）；今天逛的方向搜来的不罚 |
| 好笑 | 3 | 模型 0~4 | 锚点：没笑点 / 会心一笑 / 一两个点 / 好几次笑出声 / 想立刻发给他 |
| 上头 | 3 | 模型 0~4 | **按她自己的口味**看不看得下去（搬运、低质是她爱看的，不扣分） |
- 他对分享的反应不进分数（已经在调分享门槛 ±2，不重复算）。
- `score <BV> --fits … --funny … --hooked … --reason …`；老写法 `--score N` → `score.old-form`（带新写法提示）。分项存进 scores.json，`score` 仍是总分。
- 所有分享路径（`dm --share`、`share-dynamic`、`comment --share`）都用她**记过的**分，不信传进来的数。
- 沾了不爱看的也算「刷到垃圾」→ 心情 -1（以前封顶 6 > 4，烂片不影响心情）。
- 设置页「作息」组：6 项权重 + 不爱看封顶分。

**校准（回测她真实的 16 条标题，他会喜欢按 0 算）**：口味不沾 2~7 / 沾一类中等 8~10 / 沾一类好看 10~11 / 沾两类好看 13。
旧凭感觉的分 4 条里 1 条过 11；新标尺「沾一类且好看」约 1/3 过 → **分享线保持 11**；对上他口味的分区再加最多 4。

## 二、桌宠挪位置
**现象**：「往左走」她回「啥左边 没懂」；真走的时候是凭空平移，不像走路。
**根因**：① 我之前在人格卡里加的例子就是「他：往左边 / 你：啥左边 没懂」—— 等于教她别听懂；② 只调了 /position，没播走路动画。
**修法**：人格卡例子改成「走着」「行 挪了」（备份 persona.full-before-move-example-*）；走路 = 先朝目标方向播 dsh-pet 自己的跑步动画（原地左转奔跑，facing 左/右），起步 1.75s 后再 line 位移；「往那边 / 走开点」没说方向 → 往另一边挪（otherside）。

## 追加：权重放进配置、心情更灵活、你的对话影响心情（用户同日要求）
- **他的口味权重降低**：默认 taste 7 / him 2 / memory 2 / fresh 2 / funny 4 / hooked 3（代码算 13 分）。`scoring` 和 `mood` 两段现在**明写进 bili.config.json**（以前只有代码默认值，配置里看不到）。
- **分享线 11 → 12**：新权重下回测——平平无奇的一条都不过，沾一类又很好看的全过，沾一类且不错的约 4 成；11 会让「沾一类不错的」全过、分享太勤。±2 学习照旧（10~14）。
- **心情更灵活**：一次最多 ±3（原 ±2）、一小时 ±6（原 ±4）；分档 很开心 ≥3（原 5）、心情不错 ≥1、有点不爽 ≤-1、闷闷不乐 ≤-3；「没理她」2 小时算（原 3）、一天最多 -4；好视频只要比分享线高 1 分就 +1（原 +3）；桌宠心情动画跟着分档走（≥3 跳、≤-2 耷拉）。全部在 `mood.bands` / `mood.*`。
- **你的对话影响心情**：
  - B站私信：她自己判断（好笑/暖 +，怪她/敷衍 -）——原来就有，现在受 `mood.weights.dm` 调节；
  - **桌宠对话（新）**：桌宠挪位置那次很小的判断顺便输出语气（funny +2 / warm +1 / blame -1 / rude -2），**不多调模型**；挪位置关了也能单独判断语气（`mood.weights.pet>0` 时）；
  - **回不回**：你找桌宠或私信她 = 回了她之前主动发的（+1）；她在桌宠上主动说的也记着等你回，2 小时没回且你今天在线 → -1。
- **心情来源权重**（`mood.weights`，0~3，0 = 不影响）：video / dm / pet / reply / ignored / manual，乘在变化量上。设置页「作息」组都能调。
- 测试：mood + social 19 条（权重乘法、0 关掉、新分档、桌宠语气只调一次、挪位置关了照样判断语气）；score rubric 14 条按新权重；插件 npm test、regressions 全过。
